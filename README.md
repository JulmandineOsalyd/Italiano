# Apprendre l'Italien

Application web pour apprendre l'italien, construite avec React + Vite.

## Démarrer en local

```bash
npm install
npm run dev
```

## Déployer sur GitHub Pages

```bash
npm run deploy
```

> Pense à mettre à jour `base` dans `vite.config.js` avec le nom exact de ton dépôt GitHub.
